Hermes Backup

Hermes Backup is a personal backup integration for its owner. It uses rclone to connect to Google Drive and Restic to encrypt selected backup data before uploading it.

The integration is intended for the owner's own Google account. It is not a public backup service and does not provide access to the owner's files to visitors of this website.

Google Drive access is requested using the drive.file scope. This allows the integration to manage files it creates or files explicitly authorized for use with it, rather than requesting access to every file in the account.

The Google Drive connection is used for backup operations. It does not give an AI agent access to Google Drive, and this integration does not send Google Drive file contents to an AI model.
